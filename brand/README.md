# First Artifact — Brand exports

Printable brand identity system distilled from `BRAND.md`, `PRODUCT.md`, and `DESIGN.md`.

| File | Use |
| --- | --- |
| [`first-artifact-brand-identity.html`](./first-artifact-brand-identity.html) | Interactive / browser review (loads local fonts + logo from `../public/`) |
| [`first-artifact-brand-identity.pdf`](./first-artifact-brand-identity.pdf) | Shareable A4 brand book |
| [`export-pdf.mjs`](./export-pdf.mjs) | Regenerates the PDF via Puppeteer |

```bash
npm run brand:pdf
```

**Membership rule:** founders and builders only.

Canonical markdown source of truth: [`../BRAND.md`](../BRAND.md).
